Configurar hosts

Onde encontro a URL e o token?

No host monitorado, o install.sh imprime os dois no final. Para consultar depois, rode no host: 

sudo sed -n 's/^SYSMON_TOKEN=//p' /etc/sysmon/token.env
ss -lntp | grep 9109        # mostra o IP onde ele escuta

A URL é http://<IP_QUE_APARECEU>:9109/metrics — o mesmo IP que você passou ao instalador. O agente escuta só nesse IP; testar em localhost no host dá conexão recusada, e isso é esperado.

Se você usou o deploy.sh, ele já gerou um hosts.json com tudo preenchido — copie para junto do sysmon.pyz com o nome config.json.
